

# Кредитный скоринг: прогнозирование вероятности дефолта заёмщика

Учебный сквозной проект по курсу «Искусственные нейронные сети и прикладной интеллектуальный анализ данных».
Задача: бинарная классификация кредитных заявок и оценка вероятности дефолта заёмщика на 90+ дней в течение двух лет (соревнование [Give Me Some Credit](https://www.kaggle.com/competitions/GiveMeSomeCredit)).

---

## 2. Схема валидации и результаты экспериментов

* **Валидация:** 5-фолдовый `StratifiedKFold` с фиксированным `random_state=42` для исключения утечек данных (Data Leakage) при дисбалансе классов 93.3% / 6.7%.
* **Метрики:** Основная — `ROC-AUC`, вспомогательная — `PR-AUC`, прикладная — `F1-score` при оптимальном пороге отсечения.
* Все 5 запусков логировались в **Weights & Biases** (проект `credit-scoring`).

### Сводная таблица моделей:

| № | Эксперимент     | Архитектура          | Признаки / Предобработка                          |   OOF ROC-AUC   |    OOF PR-AUC    | Прирост ROC-AUC |
| :-: | :------------------------- | :------------------------------ | :--------------------------------------------------------------------- | :--------------: | :--------------: | :--------------------: |
| 1 | `01_baseline_naive_lr`   | Logistic Regression             | 10 сырых признаков, медиана, StandardScaler       |      0.7905      |      0.3067      |           —           |
| 2 | `02_baseline_cleaned_lr` | Logistic Regression             | Очистка по EDA (коды 96/98, клиппинг, флаги) |      0.8556      |      0.3734      |   **+0.0651**   |
| 3 | `03_lightgbm_fe`         | LightGBM (GBDT)                 | 18 признаков (Feature Engineering)                            |      0.8644      |      0.3992      |   **+0.0739**   |
| 4 | `04_catboost_fe`         | CatBoost                        | 18 признаков (Feature Engineering)                            | **0.8668** |      0.4029      |   **+0.0763**   |
| 5 | `05_ensemble_blend`      | CatBoost (60%) + LightGBM (40%) | Взвешенное среднее OOF-вероятностей       |      0.8667      | **0.4045** |   **+0.0762**   |

### Ключевые выводы:

* Предобработка аномалий, выявленных на этапе EDA (спецкоды просрочек 96/98, экстремальные хвосты утилизации и двухрежимный DebtRatio), дала разовый прирост **+0.0651** к ROC-AUC без усложнения модели.
* Финальной моделью выбран **CatBoost** (OOF ROC-AUC = **0.8668**). Модель преодолела целевую планку 0.86 и показала наименьшую дисперсию по фолдам (± 0.0038).
* Анализ важности признаков через **SHAP** показал, что ведущими факторами риска выступают утилизация лимита по картам (`RevolvingUtilizationOfUnsecuredLines`), созданный признак суммарных просрочек (`Total_Past_Due`) и возраст (`age`).

## 3. Инструкция по воспроизведению

1. **Клонирование репозитория и переход в проект:**

   ```bash
   git clone <URL_РЕПОЗИТОРИЯ>
   cd give-me-some-credit-scoring
   ```
2. **Создание и активация виртуального окружения:**

   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # Linux / macOS:
   source .venv/bin/activate
   ```
3. **Установка зависимостей:**

   ```bash
   pip install -r requirements.txt
   ```
4. **Запуск ноутбуков:**
   Данные должны находиться в папке `data/raw/` (`cs-training.csv` и `cs-test.csv`). Запуск выполняется последовательно:

   * `notebooks/01_eda.ipynb` — воспроизведение разведочного анализа данных и визуализаций.
   * `notebooks/02_baseline.ipynb` — воспроизведение наивного и очищенного бейзлайнов, расчет порога и матрицы ошибок.
   * `notebooks/03_advanced_model.ipynb` — генерация признаков, обучение LightGBM/CatBoost, ансамблирование, SHAP-анализ и инференс на тесте.
